## Варіант 7 — Розсіювання викидів точкового джерела (ОНД-86)

### Вихідні дані контрольного розрахунку (діоксид азоту NO₂)
Джерело: стаціонарна труба котельні/ТЕЦ у м. Києві (рівнинна місцевість, η = 1):
- Висота джерела: H = 40 м
- Діаметр гирла: D = 1.2 м
- Швидкість виходу газів: w₀ = 8.0 м/с
- Температура газів: T_г = 135 °C
- Середня максимальна температура липня для Києва (ДСТУ-Н Б В.1.1-27:2010): T_пов = 25.6 °C
- Коефіцієнт стратифікації (ОНД-86, п. 2.2): A = 180
- Потужність викиду NO₂: M = 12.0 г/с
- Коефіцієнт осідання для газу (ОНД-86, п. 2.5): F = 1
- Фонова концентрація (Наказ № 286): C_ф = 0.045 мг/м³ (45 мкг/м³)
- ГДК м.р. для NO₂ (Наказ МОЗ № 52): 0.20 мг/м³ (200 мкг/м³)

### Покроковий ручний розрахунок
1. **Різниця температур:**
   ΔT = T_г − T_пов = 135 − 25.6 = 109.4 °C
2. **Об'ємна витрата газів (ОНД-86, ф. 2.2):**
   V₁ = (π · D² / 4) · w₀ = (3.141593 · 1.2² / 4) · 8.0 = 9.0478 м³/с
3. **Параметр f (ОНД-86, ф. 2.3):**
   f = 1000 · (w₀² · D) / (H² · ΔT) = 1000 · (64 · 1.2) / (1600 · 109.4) = 76800 / 175040 = 0.43876 (< 100)
4. **Параметр v_m (ОНД-86, ф. 2.4а):**
   v_m = 0.65 · ∛(V₁ · ΔT / H) = 0.65 · ∛(9.0478 · 109.4 / 40) = 0.65 · ∛24.7457 = 0.65 · 2.9141 = 1.8941 м/с
5. **Параметр v'_m (ОНД-86, ф. 2.4б):**
   v'_m = 1.3 · (w₀ · D / H) = 1.3 · (8.0 · 1.2 / 40) = 0.312 м/с
6. **Коефіцієнт m (ОНД-86, ф. 2.5а, при f < 100):**
   m = 1 / (0.67 + 0.1√0.43876 + 0.34∛0.43876) = 1 / (0.67 + 0.06624 + 0.25836) = 1 / 0.99460 = 1.0054
7. **Коефіцієнт n (ОНД-86, ф. 2.6б, при 0.5 ≤ v_m < 2):**
   n = 0.532 · 1.8941² − 2.13 · 1.8941 + 3.13 = 1.9087 − 4.0345 + 3.13 = 1.0042
8. **Максимальна приземна концентрація C_m (ОНД-86, ф. 2.1):**
   C_m = (A · M · F · m · n · η) / (H² · ∛(V₁ · ΔT))
   C_m = (180 · 12.0 · 1 · 1.0054 · 1.0042 · 1) / (1600 · ∛989.828) = 2180.80 / (1600 · 9.9660) = 2180.80 / 15945.56 = 0.13677 мг/м³
9. **Коефіцієнт d (ОНД-86, ф. 2.13б, при 0.5 < v_m ≤ 2) та відстань X_m (ф. 2.12):**
   d = 4.95 · 1.8941 · (1 + 0.28 · ∛0.43876) = 9.3760 · 1.2128 = 11.3709
   X_m = ((5 − 1) / 4) · 11.3709 · 40 = 454.84 м
10. **Перевірка нормативу (C_m + C_ф ≤ ГДК м.р.):**
    C_сумар = 0.13677 + 0.045 = 0.18177 мг/м³ ≤ 0.20 мг/м³ (норматив дотримано, K = 0.9089).
